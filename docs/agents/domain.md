# Domain Docs

This is a single-context repository.

## Before exploring

Read when relevant:

- `CONTEXT.md` at the repository root — project glossary and domain concepts.
- ADRs under the repository's established `docs/04_adr/` directory.

If a file does not exist, proceed silently. `/domain-modeling` creates or extends these documents only when terminology or a durable decision is resolved.

## Vocabulary

Use terms as defined in `CONTEXT.md` in issues, plans, tests, and code. If a needed concept is missing, reconsider whether it is new terminology or a real glossary gap.

## ADR conflicts

Surface conflicts with existing ADRs explicitly instead of silently overriding them.
